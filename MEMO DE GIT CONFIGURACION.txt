### Editar "reescribir un commit" Git
	"""
	Modificar el último commit (Aún no subido)

	Si te equivocaste en el mensaje o olvidaste incluir un archivo en el último commit que hiciste, usa el comando --amend.
	• Para cambiar solo el mensaje:"""

git commit --amend -m "Nuevo mensaje corregido"
	"""• Para añadir archivos olvidados o corregir código:
	1. Realiza los cambios en el archivo y guárdalo.
	2. Añádelo al área de preparación: git add archivo.txt """
git commit --amend --no-edit

#### Modificar un commit más antiguo (Local)
	"""Si el commit que quieres cambiar no es el último, debes hacer un Rebase Interactivo (git rebase -i).
	1. Ejecuta el siguiente comando, reemplazando N por el número de commits que quieres revisar hacia atrás (por ejemplo, HEAD~3 para ver los últimos 3):"""
git rebase -i HEAD~N

	"""2. Se abrirá un editor de texto con la lista de tus commits. Cambia la palabra pick por edit (o solo e) al lado del commit que deseas modificar. Guarda y cierra el editor.
	3. Git detendrá el tiempo en ese commit. Haz los cambios necesarios en tus archivos y añade los cambios con git add.
	4. Enmienda el commit:bash """
git commit --amend --no-edit
git rebase --continue


Si el commit YA fue subido a GitHub / GitLab (Remoto)

	"""⚠️ ¡Atención! Modificar commits antiguos altera el historial. Si trabajas con más personas, esto puede causar problemas a tus compañeros.
	Si estás seguro de querer cambiarlo (por ejemplo, en tu propia rama de trabajo):
	1. Aplica cualquiera de los métodos anteriores (Opción 1 o Opción 2) localmente.
	2. Sube los cambios forzando la actualización en el servidor remoto:"""
